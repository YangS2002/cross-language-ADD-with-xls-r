# 原始 XLS-R 参照下的跨语言伪造检测适配：文献与设计稿

日期：2026-10-07。状态：研究设计，没有实现代码、启动训练或访问远程。当前目标为英语源域训练、零目标语言音频参与开发的跨语言伪造检测，同时控制 ASVspoof 2019 LA 和英语 ITW 的性能代价。已有目标域结果用于问题形成，后续这些数据的评估属于探索性复验，不能称为从未触碰的盲测。

## 1. 论文主线

多语言自监督预训练给 XLS-R 提供可跨语言使用的语音表征；仅用英语真假监督做下游适配，可能使表征和读出共同向源语言及训练攻击特化。完全冻结限制任务学习，无约束微调可能改变可迁移的语音结构。因此，提出用原始 XLS-R 作为训练参照，在学习真假区分时选择性保持自然语音的中间层关系结构。

主假设：保留原始预训练模型对真实语音帧间关系的组织方式，可以减少与源语言特化有关的有害表征变化，同时让上层与检测头继续学习伪造线索。目标收益是未见语言 EER 与跨种子稳定性改善，英语评估性能保持或只小幅下降。

这里保护的是可测量的表征结构。当前不能将其称为已识别的语言无关子空间，也不能将微调变化全部称为伪造信息。预训练权重内含多语知识不等于它已经给出可迁移真伪边界。

## 2. 与既有实验的连接

- E2 是目前最清楚的结构对照：冻结 XLS-R、相同后端，原始层状态替代层差分。五种子 DE/UK/ES 均值 18.2007/24.1364/18.0007 降到 15.4950/21.5409/12.9359；四域联合种子标准差 3.5991 降到 2.1189。说明输入如何保留预训练信息有影响；UK 仍弱，冻结本身不足以达到目标。
- E3 的 frozen_reference 相对 self_reference 有部分收益，但 UK 三种子仍为 30.30/25.12/23.84，两头都弱。原始参照可能有用，已尝试的交叉注意力实现没有完成目标。E3 与 E2 同时改变投影、交互和微调，不是微调破坏跨语言的因果证据。
- M3/M4 显示域取舍与双头互补依赖种子，为控制模型变化提供动机。它们没有证明残差幅度是根因；旧报告涉及样本顺序或门控梯度的因果解释未得到独立验证，本轮不采用，也不研究样本顺序。
- M3/M4 使用 CH/DE，E2/E3 使用 DE/UK/ES/ITW，不对不同实验时代的绝对 EER 作直接排名。旧逐域历史最佳门槛和“每个种子必须单独改善”的额外门槛不沿用。

## 4. 推荐方案：真实语音中层关系保持微调

暂用描述名 Bona Fide Relational Preservation Fine-Tuning，不声称名称或单个损失构成创新。

### 4.1 两个模型的职责

冻结参照 F0：官方 XLS-R-300M 初始化，评估模式，不训练检测头，不提供真假软标签。

任务模型 Ftheta：同一 XLS-R 初始化，Transformer 参与真假训练；保留原始层状态输入和现有检测后端。前端卷积是否冻结及 SSL dropout/masking 策略在实现前统一写入所有对照配置，不让参照约束和普通微调使用不同策略。首轮无需替换 192 维投影、双头或添加融合模块。

参照只参与训练约束。推理用任务 XLS-R 和检测头，不需要双 XLS-R、距离异常分数或目标语言适配。

### 4.2 保护对象

初版仅保护第 12 个 Transformer block 输出，即 24 层骨干的几何中点。这个选择降低搜索与过约束风险，是预设设计，不是文献证明的最佳跨语层。之后再做有限层位消融；不按目标域表现挑层。

第 12 层约束向该层及之前的可训练参数反传，不直接约束第 13–24 层，后者通过任务监督适配。并不保证上层一定保留中层信息，需诊断检验。

对真实语音施加约束：原始 SSL 教师来自自然语音预训练，将其作为真实语音参照比将其全部伪造表示也锁定更有任务依据。伪造样本仍参与完整真假监督，初版不施加参照约束。这一类条件选择必须与全样本约束比较验证。

### 4.3 关系矩阵与损失

令同一输入经两路的第 12 层输出 H0,Htheta 属于 R^(T x 1024)。两路时间位置一一对应，原 data.pad 不变。初版保留全部帧，不进行音频重采样或新增音频增广。

对每个 H，在时间轴上减去该语音的均值向量，再逐帧做 L2 归一化（分母下限 eps）。得到 U，计算 K=U U^T。中心化降低整段共有偏移的影响，逐帧归一化降低幅度变化的影响；它们都不等于消除语言、说话人或通道信息。

关系损失：

    L_rel = mean_{x in bona_fide} [sum_{i != j}(Ktheta_ij - K0_ij)^2 / (T(T-1))]
    L_total = L_detection + lambda * L_rel

对角线无需计入；K0 停梯度。若 batch 无真实语音，关系项置零；有真实语音时按真实样本数单独平均，避免原始真假数量不平衡把约束稀释。L_detection 沿用既有后端预注册训练目标，不混入新的残差、攻击损失或语言分类任务。所有输入仅为英语源域训练音频。

关系约束允许共同坐标旋转：对正交 Q，(UQ)(UQ)^T=UU^T。因此它比逐坐标复制原始特征更宽松。该等式只说明关系损失的性质，不保证整个网络跨语言能力不变；单语音内关系也不能约束跨语音的全局坐标系。

lambda 在执行前使用源域训练信号确定并写定，不用 CH/DE/UK/ES/ITW 选择。当前是研究稿，不填写未经试算的所谓最优系数。

### 4.4 训练顺序和资源

建议统一使用检测头预热，再分支到冻结、普通微调和约束微调。这是已有 LP-FT 思路，作为所有微调臂共同的训练控制，不作为新贡献。

工程草案为同一个种子先冻结训练头 3 轮，从同一个预热状态分出三臂继续 7 轮；每臂总暴露 10 轮。正式执行前根据源域日志确认预热安排并锁定。不得让约束臂额外多训、改变输入或另选头。

teacher 仅对真实样本执行到第 12 层且无梯度，可缓存原始训练输入对应的关系矩阵。缓存需含音频/权重/特征签名，仅驻留远端；本轮不生成缓存。student 仍真正微调，参照约束不等于冻结骨干。

## 5. 论文故事如何得到证据支持

建议开篇表述：多语言预训练能够提供可迁移语音表示，但单语言伪造监督无法自动维持这种迁移能力。已有模型在未见语言上有明显差距，故研究单语言适配过程中预训练语音结构与任务判别的平衡。

实验前提出机制假设：源域真假监督可能重塑自然语音的关系结构，使检测器依赖源语言/训练攻击中的判别规律。英语源域关系漂移不能单独被称为语言特化；它是一个可测的中间量。

方法从假设推出：自然语音关系是保护对象；中层是约束位置；关系对齐允许坐标适配；真假监督和不直接约束的上层提供任务学习自由度；原始模型持续提供训练参照。

若关系保持和跨语言效果同时改善、相对于普通微调的英语代价可控，并且类条件/关系形式的消融支持选择，则主张“该约束能改善单语言监督下的跨语言适配”。若没有受控语言证据，不写“已经分离语言信息与伪造信息”。

## 6. 后续验证序列：一次一个问题

本轮仅设计。随后工程筛查固定 seed20；单种子有希望才扩展预定 seed1001 和 seed7，全部保留，不承诺任意可能的种子都有效。

第一步三臂：冻结、同结构普通微调、同结构关系保持微调。主要比较普通微调与关系保持，冻结作为任务适配程度的参照。记录每轮源域完整训练目标、分类分量、关系分量、真实/伪造关系漂移、梯度与 AMP 异常；按预注册源域训练目标最低值保留 checkpoint，不按目标 EER 选权重。

第一步成立后，再逐项验证：真实语音关系约束 vs 全样本关系约束；关系约束 vs 逐点特征对齐。二者分别回答类条件选择和关系形式是否必要，分开执行，不做组合网格。中层位置和正交参数适配排在之后。

目标结果包括 CH/DE/UK/ES 的逐语言 EER 与等权均值、每个种子最差语言、三种子均值和样本标准差；ASVspoof2019 LA eval 与 ITW 单独列为英语指标，19LA dev 用于源域分析但不代替最终 eval。数据可用性及标签必须在后续执行前核对，不新增数据迁移或修复任务。

英语容忍量需预注册为两个独立差值上限 delta_19 和 delta_ITW，参考同协议普通微调，并同时列 SLS/DuaBiMamba 外部指标。19LA 基线 EER 可能很低，不给 19LA 与 ITW 生硬共用相同绝对退化阈值。本轮没有核验完整19LA基线，因此不虚设数值。ITW 不用于选择 lambda 或 checkpoint。

平均改善必须与每域/最差值一起看；不要求每个域达到历史单域最好，也不允许均值掩盖明显失败。目标是预定种子下有较好的跨语言表现，并在英语代价可控条件下比普通微调更稳。

## 7. 可能结果及其解释

| 结果 | 可作的判断 |
|---|---|
| 普通微调相对冻结未出现更大的真实语音结构漂移或跨语代价 | 当前特化机制缺少该对照支持；不能借 E3 代替证据 |
| 关系漂移下降，跨语言无改善 | 保护这些关系不足以解决问题，或检测头没有利用它们 |
| 跨语言改善，但关系漂移没有下降 | 不能用关系保持解释收益，需要检查实现与其他训练差异 |
| 跨语言改善，英语严重退化 | 约束阻碍任务学习，没有完成目标 |
| 一个种子改善、其他种子失败 | 值得分析但不能宣称稳定有效 |
| 跨语与英语目标达成，漂移和消融也吻合 | 支持所提适配机制；仍不等于原始预训练所有跨语功能已保留 |

## 8. 与最近工作的差异和创新边界

STaR 已有帧间关系蒸馏；OCKD 已有真实语音选择性训练；OFT 已有结构保持适配；语言正交化已经直接研究零目标跨语伪造检测。因此本设计的潜在贡献是以跨语言任务为对象，解释单语言适配中的结构变化，证明真实语音中层关系的选择性保持能改善迁移与英语表现的平衡。不能把几个已有部件的组合名称当作创新证据。

当前推荐先把这一个假设验证清楚。实验若支持，再以对照和分析完善论文；实验若不支持，修改机制假设，不事后把任意收益改写成预先成立的语言故事。
