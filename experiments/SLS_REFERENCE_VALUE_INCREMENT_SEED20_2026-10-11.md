# 原始功能 Value 基座＋全宽任务 Value 增量

## 实验目标

原始 Q/K 已在 seed20 得到较好的跨语言平均，但三个固定种子的第8阶段四跨语均值为11.1029/13.7855/15.2732，UK最坏22.0827。固定关系并未固定被传递的特征：A0 Vtheta(Ztheta)仍受任务上下文变化影响。本轮只检验一个结构假设：持续保留原始上下文上的 Value 功能输出，同时保留任务参数变化及其对任务上下文的读取，是否改善跨语言平均/最坏域及英语 ITW。漂移是可用的解释假设，不是已验证的失效原因；单seed不能证明稳定性或任意seed有效。

## 基本设置

- 每层/每头：U=A0[V0(Z0)+(Vtheta-V0)(Ztheta)]。A0由全冻结原始XLS-R24层实际Q/K计算。原始项读取原始实际注意力输入；增量读取任务实际输入。任务out/残差/FFN/归一化正常适配，任务Q/K和原卷积冻结。Vtheta保留全宽原有参数，并非小规模低秩增量。无额外可训练参数、正交/重建/对比/辅助损失、gamma或额外分类头。
- 工程计算：分别计算V0(Z0)与(Wtheta-W0)Ztheta+(btheta-b0)，FP32混合后恢复native dtype，通过PyTorch MHA的static_v接口提供已投影Value；空通道dummy投影避免重复计算未使用Value。保持共享MHA的Q/K、softmax、mask和task out。FP32参数先求差再BF16投影；这不是将task V的原权重作用在变动上下文上，也不是直接叠加两个完整Value。初始化增量为0，应保持原始网络等价，须实际自检。
- SLS完全沿用原Attention的全宽1024/maxpool单头及可导层门控。源ASVspoof2019 LA25380条（真2580/假22800），自然比例，假0.1/真0.9加权NLL；batch16/BF16、lr SSL/head均1e-6、wd1e-4、clip5、4workers。data.pad64600和历史加载不变；不重采样、RawBoost/噪声、样本顺序研究或目标标签训练。
- 单候选seed20，不重跑历史SLS/QK背景对照。复用SHA一致的同seed三轮源冻结SLS预热（SHA32454f00414be2172ca7d84bfa631c3a8b551f45d415816354b0597645904742）；新建原始任务骨干、加载后端和预热RNG、fresh AdamW，正式只总epoch4–8。预热影响未被排除，本轮条件于相同预热。
- 第4/8完整评估CH/DE/UK/ES/ITW。唯一best按截至阶段最低完整源分类NLL历史batch聚合选择，另记精确加权值；不用目标域挑checkpoint/head/seed。第4一般域间取舍继续到8；严重失败停止仅限：相对同阶段Attention四域均值差>3pp且至少两跨语域差>5pp；或ITW差>3pp且跨语总差>=0；或某跨语EER>35且差>8pp。沿用既有候选的快速失败规则，不依据阶段结果调方法。正式75分钟硬预算，数值/OOM/磁盘/预算异常停止且不重跑。
- 小型日志、CSV、JSON逐轮保留；权重仅唯一best与第4源best快照各约1.14GB，无教师/Adam/逐轮模型副本，不能精确续训。现有持久盘约5.7GB余量足够本轮含原子替换临时文件；不删除历史，不把数据写系统盘。仅上传新文件，共享trainer/model/data/train按历史SHA核验而不覆盖；不Git提交为有效成果。
- 结果逐域列出四跨语平均/最坏、CHDE联合和ITW，同阶段原QK及论文整行SLS12.26/19.71/21.13/9.69/7.46、DuaBiMamba17.32/23.57/11.89/15.83/6.71。不以平均改善掩盖失败，不设逐域历史最佳门槛。UK已用于研发诊断须披露。无自动扩种子；单候选有效后讨论固定1001/7。
- 假设边界：任务out/FFN/SLS仍可忽略或抵消原始功能项，增量不等于纯伪造或内容解耦。该方法是对已有固定Q/K方法的一个结构测试，不声称理论保证跨语言性能、稳定性或首创双路思想。
