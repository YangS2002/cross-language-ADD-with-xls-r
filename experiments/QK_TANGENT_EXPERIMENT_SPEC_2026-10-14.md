# 原始 QK 下的一阶骨干适配：首轮实验定义

日期：2026-10-14。状态：研究定义已收敛；尚未实现模型、完成显存验证或启动训练。用户当前要求分析直到可以进行实验，不把本文件当作启动授权。已有关系约束队列已停止。

## 1. 唯一研究问题

在固定实际教师注意力 A0(x) 时，限制 XLS-R 骨干的非线性参数共适应，能否改善仅英语监督后的跨语言伪造检测？

已有事实：原始 QK 不同种子源训练拟合都很好，但跨语言结果不同；UK 的来源组内排序也不同。新增影子注意力 KL 在 seed20 失败。这些事实不证明 Jacobian 漂移是原因，也不证明预训练参数响应具有语言不变性。

竞争解释：源监督和后端可能从第一次更新就选择不同判据；伪造检测可能需要非线性适配；原始训练也可能已接近线性区域。本实验必须允许这些解释否定候选。

## 2. 固定候选，不增加第二种机制

F(theta, x; A0) 返回原始 QK 模型的全部 24 层骨干状态。theta 只包含原始 QK 基线可训练的骨干参数；theta0 为其预训练初始化。A0 在求导中视为固定，但仍随输入音频变化。

候选定义：

    H_tan(theta, x) = F(theta0, x; A0(x))
                   + D_theta F(theta0, x; A0(x))[theta - theta0]

后端接收这 24 层状态，沿用当前 SLS。不能线性化整个分类器再声称可与任意非线性后端直接互换；本实验仅线性化骨干。整个联合优化不保证凸、不保证种子无关。

模型仍依赖音频的非线性预训练计算，仅对骨干适配参数为仿射函数。它保持初始化处的参数 Jacobian，不保持所有输入 Jacobian、特征距离或跨语言决策。

训练和推理均使用 H_tan；不能训练后将 theta 直接装回普通 XLS-R 推理。输出接口兼容不同后端不等于已经验证跨后端有效。

## 3. 实现边界：传播基值与增量

采用每个算子的 (z0, dz) 双状态传播；z0 为预训练基值，dz 为从全网络一阶展开传播来的增量。仅在向后端导出每层状态时使用 z0 + dz。不能将两者相加后输入普通下一层，否则重新引入高阶项。

列向量约定，线性算子 y = Wz + b：

    y0 = W0 z0 + b0
    dy = W0 dz + (W - W0) z0 + (b - b0)

保留 W0 dz。旧 ValueIncrement 的初始输入梯度缺失不应重现。删除的是参数增量与输入增量乘积，而不是上游梯度通路。

每头实际注意力：

    V0 = Wv0 z0 + bv0
    dV = Wv0 dz + dWv z0 + dbv
    C0 = A0 V0
    dC = A0 dV

拼接后的输出投影按相同线性算子规则处理。Q/K 及 A0 不引入适配增量或导数。

非线性算子：y0 = f(z0)，dy = Df(z0)[dz]。残差分别相加。LayerNorm 同时保留输入方向导数及 gamma/beta 参数增量，方差计算保留当前实现的 epsilon。GELU 使用实际实现对应的导数，不更换激活函数。

输入 LayerNorm、post_extract_proj、位置卷积及 Transformer 内原本可训练的归一化/FFN均纳入同一个展开；冻结声学卷积保持冻结。位置卷积当前使用 weight_norm，必须对原 g/v 参数坐标求导，不能改成直接训练展开后的卷积核，否则参数化与 AdamW 衰减发生变化。

已通过只读 SSH 核对当前安装的 fairseq TransformerEncoder 和 TransformerSentenceEncoderLayer 源码。应遵循实际模型的 pre/post LayerNorm 配置、SamePad、序列 padding 和层输出位置，不另猜配置。尚未加载本轮模型做运行验证。

不显式构造 Jacobian。使用逐算子方向导数实现；固定基值分支不保留对 theta0 的反传图，增量分支保留对 theta 的梯度。

## 4. 参数与优化器公平性

- 优化器仍更新绝对参数 theta，初始化为 theta0；前向内部计算 theta-theta0。
- 不把 AdamW 权重衰减从 theta 偷换到零初始化增量，也不增加对增量的正则项。
- 沿用原骨干可训练参数名集合，不额外冻结 FFN、位置卷积或归一化。
- 原分类 NLL、类别权重、两组学习率、weight decay、梯度裁剪全部不变。
- 无辅助 KL、攻击头、解析读出、低秩分解、噪声、混合系数或层选择搜索。
- 参数差在 FP32 中计算，避免先转 BF16 再相减抹掉小更新；骨干矩阵计算继续沿用 BF16 协议，归一化和导数中的稳定统计使用适当 FP32。

## 5. 首轮实验矩阵

仅两个正式运行，均为 seed20：

1. 原始 QK 匹配基线。
2. 原始 QK + 全骨干一阶适配。

均从相同的历史 seed20 三轮后端预热权重和 RNG 状态开始，重建预训练骨干、fresh AdamW。当前原始 QK 终点权重此前已清理，匹配基线重新训练也用于获得相同条件下的机制记录。

源数据 ASVspoof2019 LA，25380 条，真实2580/伪造22800；自然比例，batch16，真实0.9/伪造0.1加权 NLL；head/SSL lr均1e-6，weight_decay1e-4，clip5，4 workers。data.pad64600 与加载方式保持。

正式总 epoch4--8；第4及第8阶段完整评估 CH/DE/UK/ES/ITW，按最低完整源分类训练 NLL 选择权重。第4目标结果仅报告，不用于修改候选或选择最佳目标阶段。两臂均按固定轮数完成；数值错误或资源不足则停止并如实标记未完成。

每臂保留第4快照、源选best、逐条分数、日志及小型训练记录，不保存完整 Adam 状态。不得覆盖历史实验目录。

第一轮不跑 MLP/Mamba，不启动其他候选，不自动扩种子，不扫描系数。首轮完成后再判断是否值得固定验证1001与7。seed20结果不能说明种子稳定性。

## 6. 必要实现验证，而非先做诊断工程

正式训练前只做短验证：

- 初始化24层输出及分类输出与原始 QK 对齐；FP32分类梯度应在数值误差范围内对齐，不能仅检查梯度非零。
- 非零参数增量下，少量算子/层的方向导数与自动微分 JVP 对齐；确认完整增量传播，不把残差项遗漏或重复计算。
- 确认原可训练参数集合、教师冻结、内存与单步耗时。显存不足不自动缩减 batch、层数或冻结参数以冒充同一候选。

自检更新丢弃，正式恢复同一预热/RNG。当前 fairseq 即使 eval 也会消耗每层 NumPy 随机数，增量实现须维持原任务路径的 RNG 语义；额外基值计算不能改变训练音频顺序。

实际全模型数值误差、显存和耗时仍待实现后短测；不能把论文的同量级开销当作当前4090可运行证明。不得因沿用旧4500秒配置而将候选运行更慢误判成科学失败。

## 7. 结果如何回答问题

主要证据为两个正式训练模型的完整目标域 EER/AUC，而非辅助指标。报告四跨语言均值、最坏域及ITW，并保留各域结果；不把ITW称为另一种语言。

在正常保存阶段，可对预先固定的少量源样本记录：

    R(theta,x) = F(theta,x;A0) - H_tan(theta,x)

按层报告 R 相对于实际特征改变量的大小，及同一后端下的分数变化。该记录用于判断两种计算是否有实际差异，不用于选择权重或调参。余项小不直接证明它不影响边界，余项大也不证明它有害。

同参数替换为切线特征的反事实评估存在后端输入失配，只能是补充诊断，不是第三个训练臂，也不作为首轮开跑前置。不额外开展全目标域诊断搜索。

- 源拟合正常、跨语言改善：支持进一步检验这个具体适配约束，但未证明多语言知识是收益的唯一原因。
- 源拟合明显受损且迁移差：候选丢失必要适配能力，不自动改层或增加残差系数补救。
- 两种计算及结果接近：降低该方向优先级，不以复杂性代替有效性。
- 源拟合相似但迁移更差：否定本次固定初始化响应的改进假设。
- 后续固定种子没有改善平均和较差种子：不宣称稳定性提升；标准差下降不能靠所有种子都变差实现。

## 8. 文献与创新边界

TAFT（ICLR2024）：https://arxiv.org/html/2307.08122v3
已有全网络一阶展开及逐算子高效计算先例。论文主要验证视觉任务，使用rescaled square loss及增量正则，并讨论初始化偏置。本候选不照搬这些额外设置，不声称论文已经证明跨语言伪造检测有效。

Fine-Tuning can Distort Pretrained Features（ICLR2022）：https://arxiv.org/html/2202.10054
支持考虑读出与特征更新耦合，但不能把其线性模型条件直接套到预热后的SLS。

Taylor展开、固定Jacobian和TAFT本身都不是本项目原创。可研究的贡献须由原始QK条件下的跨语言收益、固定种子表现及机制证据建立，当前尚无这些新结果。
