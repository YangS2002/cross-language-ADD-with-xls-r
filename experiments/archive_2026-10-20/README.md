## 文件组织

- `tools/`、根目录及 `src/`：以服务器实际版本为准的代码；本地独有工具同时补齐。
- `experiments/configs/`：实验配置，路径可能指向原服务器环境。
- `experiments/`：研究计划、论文笔记、实验报告、诊断汇总与日志。
- `models/<实验名>/`：仅保留 JSON、CSV、日志等文本记录，包括评估指标和逐样本评分，不包含模型权重。
- `experiments/handoff_2026-10-11/`：报告汇编、评估表、清理和交接清单；压缩包未上传。
- 本目录下 `local_variants/`、`server_variants/`：两端存在差异的历史副本，不作为当前训练入口。

## 版本来源

`server_manifest.json` 记录服务器源文件的 SHA256、大小及排除文件；`merge_manifest.json` 记录两端 Git 起点、本地补充和差异副本。研究 Markdown 同名冲突采用本地整理版本，代码和实验原始记录冲突采用服务器版本。

不上传训练权重、优化器状态、预训练权重、二进制特征/诊断缓存、音频数据集、依赖压缩包和临时连接文件。历史上已跟踪的权重及依赖压缩包在本次版本中移除跟踪，不改写旧 Git 历史，也不删除服务器原文件。

## 解释边界

历史 `status.json`、进程号和端口只是当时记录，不表示当前仍在运行。源训练集指标不能当作独立验证指标。目标集已参与研究诊断。多证据辅助方案尚未正式实现；各文档中的撤回与后续修正优先于早期计划。部分报告引用的权重或二进制诊断文件需在服务器另行获取。
