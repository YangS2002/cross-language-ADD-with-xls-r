# E3 预注册方案：原始 XLS-R 参照与全量微调 XLS-R 的跨层交互

状态：仅定方案；尚未实现、上传或启动。取代 `E3_CONTROLLED_XLSR_ADAPTATION_DESIGN_2026-09-28.md` 的单路上层微调设计。前述设计撤回，不当作失败实验。

## 唯一主假设

XLS-R 原始权重的冻结分支保留预训练得到的跨语言语音参照；同一初始权重出发、全量微调的分支学习源域伪造线索。对每段音频让微调分支按层、按帧向冻结分支检索上下文，可能比仅使用微调表示更稳定地检测未见语言和伪造方法。**这是假设，不预设冻结分支已经在本任务上具备有效的跨语言检测能力。** 不使用参数接近约束来代替两份权重同时存在，也不做末端分数平均。

## 模型：task-query / reference-key-value

同一音频输入两份 XLS-R 300M，初始化均为 `/root/rivermind-fs/xlsr2_300m.pt`。`F_0` 永久冻结且 eval；`F_t` 的所有 XLS-R 参数参与源域训练，前向时关闭 SSL dropout/masking 以便对照，梯度保持打开。两份模型逐层产生 24 个对齐的 `[B,T,1024]` 状态；沿用 E2 的 `layers[1:]` 共 23 层，不使用相邻层差分。维持当前 `torchaudio.load` + `data.pad` 64600 样本截取/重复协议，不重采样、不用 RawBoost 或加噪。

对每个帧位置，分别以可学习的线性投影和 LayerNorm 得到 23 个 192 维层 token：`A=P_0(F_0(x))`、`U=P_t(F_t(x))`。以 `U` 为 query、`A` 为 key/value，仅在同一帧的 23 个层 token 间做 6 头交叉注意力：`C=CrossAttn(Q=U,K=A,V=A)`；融合 token `Z=LayerNorm(U+C)`，输入与 E2 同构的双头层级检测器（将 raw-layer token 接口用于 `Z`）。主分数是两个检测头 logits 的固定等权平均，再取 bona fide softmax；不从 DE/UK/ES/ITW 学融合系数。可学习投影和注意力只由源域监督训练；冻结的是 `F_0` 的 XLS-R 参数，而非整个参照处理路径。

该结构不是原始/微调 logits 末端平均：微调层 token 决定查询，原始层 token 提供被检索内容，交互发生在检测头之前。它也不直接假设微调后和原始状态可相减。交叉注意力权重只能作辅助诊断，不能单独证明语言不变性或伪造因果线索。

## 必需的配对对照，而非方法网格

1. **C2：原始参照交叉注意力**，即上述方法。
2. **C1：微调自参照注意力**。保留完全相同的 `P_0`、`P_t`、交叉注意力和检测头，将 C2 的 key/value 输入 `P_0(F_0(x))` 唯一替换为 `P_0(stopgrad(F_t(x)))`；query 仍为 `P_t(F_t(x))`。这样两臂参数量一致，key/value 到 XLS-R 的梯度也同样截断，唯一研究性变化是参照表示来自原始权重还是任务微调权重。它比普通 FT-only 更严格：若 C2 优于 C1，不能简单归因于多一层注意力或更多检测头参数。
3. **C0：冻结原始参照单路**。已有 E2 raw-layer 五种子结果可提供历史尺度，但后端不完全同构，不能充当 C2 的严格因果对照。若 C2/C1 显示希望，再补做同构 C0；不把 E2 历史结果伪装成完全配对实验。

C1/C2 使用相同预定种子、相同 `F_t` 初始化、相同检测器及交叉注意力初始化、相同训练样本顺序、学习率、有效 batch、轮数和 checkpoint 规则。两者唯一研究性变化是注意力的 K/V 来自原始 `F_0` 还是当前 `F_t` 的停止梯度副本。另报告每个检测头 A/B，但不用目标域选头。若 C2 改善，还需同一模型内的冻结参照失活诊断；该诊断存在分布偏移，仅作佐证而不作唯一证据。

## 解释边界

只有 C2 相比容量匹配 C1 在多数预定种子和多个域稳定改善、且原始参照失活确有影响时，才能支持“原始参照和任务适配互补”的解释。即便如此，也只能说与该机制一致；不能从结构命名直接推出冻结 XLS-R 自动提供跨语言泛化。若 C2 与 C1 相当，则双路额外开销和论文机制都缺少证据，应如实停止该方向。论文新颖性另需查重与相关工作比较；“两个 XLS-R 分支”本身不是充分贡献。
