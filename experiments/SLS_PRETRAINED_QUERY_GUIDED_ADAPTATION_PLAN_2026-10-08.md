# 原始 Query 引导的 XLS-R 任务适配：实施前登记

日期：2026-10-08。状态：设计完成，已只读核对本地旧代码、报告和远程 fairseq；尚未编写新模型、进行数值前向检查或启动训练。本文件不是实验完成记录。

## 1. 从现象到一个可检验假设

已有纯 SLS seed20 的四跨语言平均 EER 随总 epoch 4/8/10 为 12.9235/15.9629/16.7085%，ITW 为 8.2601/7.7096/7.6936%。源训练损失继续下降，但跨语结果恶化，英语 ITW 并不同时恶化。不能把这个现象归因于随机样本顺序、采样率或已经证实的内容捷径。

UK 表征诊断中，原始/微调编码器的源域监督线性读出在 UK 上均较差，且微调后在 layer8/16/24 均更差；同一微调表征换成 UK 监督读出，在既定书籍划分上可以接近零 EER。因此：

- 不支持“微调后的 UK 真假信息完全消失”。
- 不支持“只有 FC1 或最后分类头出问题”。
- 值得研究的是编码器与读出共同适配后，源监督偏好的判别方向/信息组织方式能否迁移。
- 尚未定位到注意力、Query 或纯语言内容；目标可读出性也可能包含生成器/录音等线索。

**本轮假设：** 英语伪造监督同时改变上下文检索和特征变换，可能形成源域专用的检索—判别协同。让原始多语言 XLS-R 提供逐层的上下文检索 Query，同时允许任务分支学习 Key/Value、输出映射和 FFN，可能在保留伪造检测学习能力的同时，减轻这一协同的源域特化。

这是设计假设，不是已由诊断证明的原因。实际研究问题是：这种具体限制能否改善零目标语言训练的五域 EER，并在后续固定种子上维持收益？

## 2. 文献支点与限制

[Fine-Tuning can Distort Pretrained Features and Underperform Out-of-Distribution](https://arxiv.org/abs/2202.10054) 支持考察特征与读出的共同适配，但其理论不能直接证明本任务的 Query 失效。已有 3 轮冻结后端预热不再包装成新的 LP-FT 方法。

[On the Surprising Effectiveness of Attention Transfer for Vision Transformers](https://arxiv.org/html/2411.09702v1) 已经研究原始 Q 复制、学生学习 K/V 的变体：它允许注意力随任务改变，比固定整个注意力矩阵灵活。不过其主设置的学生随机初始化；本轮学生使用完整预训练初始化。该文的分布偏移实验也显示注意力迁移不包含全部鲁棒性收益。

[What Does Attention Transfer Transfer?](https://arxiv.org/html/2608.18399v1) 是 2026 年预印本，提示注意力结构改变不必然带来鲁棒性改变；研究范围是视觉，不直接否定或证明本方案。

所以 Query Copy 不是本工作发明的新原语；跨语言语音应用、有效机制和创新贡献仍需实验建立。不将视觉结果直接写成跨语言语音结论。

## 3. 唯一候选：逐层原始 Query，任务 Key/Value

同一波形进入原始分支 F0 和任务分支 Fθ，两者均由同一已核验 XLS-R 初始化。原始分支始终冻结，训练与推理均存在。

在每个 Transformer block l 的注意力入口，取真正传给该层 self_attn 的原始隐藏序列 U0[l] 和任务隐藏序列 Uθ[l]，而不是 block 输出或时间平均量：

```text
Q0[l] = U0[l] Wq0[l] + bq0[l]
Kθ[l] = Uθ[l] Wkθ[l] + bkθ[l]
Vθ[l] = Uθ[l] Wvθ[l] + bvθ[l]
A[l]  = softmax(Q0[l] Kθ[l]^T / sqrt(d_head) + 原注意力 mask)
O[l]  = concat_heads(A[l] Vθ[l]) Woθ[l] + boθ[l]
```

之后沿用任务 block 原有残差、LayerNorm、FFN 和层顺序。原始特征不与任务表征相加、不直接进入分类器，不平均两个真假分数。

采用全部 24 层、全部原有注意力头，无目标域选择层/头，无新增层选择超参数。不是时间 mean/std 线性后端，不是原始注意力矩阵硬复制。

| 部件 | 本轮设置 |
|---|---|
| 原始 XLS-R | 全冻结、eval、no_grad；提供 24 层实际 Query |
| 任务卷积特征提取器 | 保持现有 SLS 冻结设置 |
| 任务 q_proj | 权重和偏置冻结，保持原始值，用于对 U0 投影；不从任务 Uθ 产生 Query |
| 任务 k_proj/v_proj/out_proj、FFN、encoder 内归一化/位置卷积 | 沿用当前允许的 encoder 参数微调，不缩减为小适配器 |
| 任务 post_extract_proj/layer_norm | 沿用当前可训练设置 |
| SLS 后端 | 24 层、1024 全宽，原门控、BN、SELU、3×3 max pool、22847→1024→2，单分类头 |
| 损失 | 现有源域 weighted NLL，fake 0.1 / bonafide 0.9；无新增正则 |

重要：`FullWidthSLS.forward` 为旧参照对照而 detach 了门控输入；本轮必须沿用 `ConditionalResidualSLS(arm='sls')` 的**不 detach**门控梯度路径，不能直接复用前者而偷偷改变纯 SLS 基线。

原始 Query 是原始模型在每条实际输入上的激活，不等于“只冻结任务 Wq”。后一种做法仍会因 Uθ 改变而改变 Query。

## 4. 内容问题如何进入故事

不宣称 Q 是内容、V 是伪造，也不把所有内容方向删除。伪造线索可能依赖语音上下文，删除内容可能同时删除有用线索。

本轮处理的是**单语言监督对上下文检索方式的重写自由度**：原始分支给出不随本次英语伪造标签更新的 Query，任务分支仍能用 K/V/FFN 学习上下文条件下的伪造判据。它不是已完成“内容解耦”或“内容影响削弱”的实现；只有跨语结果和后续机制证据支持时，才能进一步讨论减轻语言特化。

Q 固定不等于 A 固定，任务 K 仍可使 A 显著改变；残差、FFN、分类头也可形成源域偏差。若 V 各帧相同，则 A V 与 Query 无关。保留原始 Query 不保证模型真正使用其跨语言信息，更不保证种子稳定性。

不因这些风险预先添加第二模块。本轮首先测实际效果；注意力熵、CKA 或源损失变好均不能代替 EER。

## 5. 与已失败方案的实质差别

| 旧方案 | 原始信息接入方式 | 本轮差别 |
|---|---|---|
| E3 双路 | SSL 输出后 192 维；任务 Q / 原始 K、V；每帧跨层注意力；双头 | 在 SSL 内原宽时间注意力；原始 Q / 任务 K、V；单 SLS 头 |
| SLS_reference | 原始层时间摘要只决定 SLS 层门控 | 原始信息作用于每层上下文检索，不替换 SLS 门控 |
| conditional_residual | 聚合后预测/修正表征 | 无预测器、无相加残差、无重建目标 |
| RP/正交/内容读出约束 | 保持几何或删除可读出方向 | 不整体保持特征，不强制统一伪造方向，不训练额外内容头 |

这些差别说明本轮不是旧代码重跑，不证明其中哪个差别导致收益。相对 E3 存在多个结构差别，不将两者对比包装成单因素消融。

## 6. 已核对的工程落点

SSH 30646 可用。远程 PyTorch `2.5.1+cu121`，fairseq 位于仓库内 `fairseq-a54021305d6b3c4c5959ac9395135f63202db8f1`。

`MultiheadAttention.forward` 常规 CUDA 路径调用 `F.multi_head_attention_forward`，直接使用投影权重，绕过 `q_proj.forward`。**不能用 q_proj 输出钩子替换 Q 而以为修改已生效。**

实现方式固定为：原始 self_attn 的模块入口钩子逐层收集 U0；任务注意力用一个局部包装调用与已安装 fast path 等价的 functional 计算，传 `query=U0, key=Uθ, value=Uθ`，独立投影权重。q_proj 固定为同一原始 Wq/bq，其余投影仍用任务权重。显式保持 bias、head 数、padding mask、缩放、输出投影和输出格式。保留原参数命名，不复制/覆盖整个 fairseq 文件。

对未支持的 incremental/static_kv/特殊导出路径明确报错，不静默退回会忽略外部 Key/Value 的 self_attention 分支。

缓存取自注意力**入口**，兼容每层 pre/post-LN 的实际位置；不得从 layer_results 推断入口。编码器会把序列补齐到 required multiple 后才进层，layer_results 最后去 padding，因此内部 T 可大于 SLS 的 201。原始/任务入口 T、batch、padding mask 必须一致；不得先裁到 201 再替换 Query。

原始分支用 no_grad，不用会影响后续反向使用缓存的 inference_mode；每批缓存用完即释放，不保存全数据 Query 或注意力矩阵。原始额外前向保留并恢复 NumPy RNG，避免 fairseq 在 eval 下仍抽 layerdrop 数导致新的随机流程混杂。

已安装关键函数 source SHA256：

```text
MultiheadAttention.forward:

TransformerEncoder.extract_features:

```

只新增独立 `tools/sls_pretrained_query_model.py`、`tools/train_sls_pretrained_query.py` 和本候选 config，不整体覆盖 `src/model.py`、`train.py`、fairseq 或远程未提交文件。只上传新增文件。

## 7. 开跑前必要检查，不是新增背景实验

只在少量固定源域样本上做数值/梯度/资源检查，不测目标域来挑实现版本：

1. 同一预训练初始化和预热后端，冻结 eval 后端统计，以 FP32 比较纯 SLS 与候选的 24 层输出及最终分数；BF16另检查合理数值误差。应初始化等价，不要求不同计算分支逐位一致。超出预先记录的误差容限则修实现，不训练。
2. 一次反向确认原始分支和 q_proj 没有梯度，任务第1/24层 K/V/FFN 及后端有有限非零梯度；确认全部层确实调用外部 U0。
3. 两三次更新验证 loss 有限，记录实际 trainable 参数数、显存与保存 payload 大小；自检更新不得进入正式训练权重，正式模型重新加载并恢复共同 RNG。
4. 一个固定源 batch 做 Query 改变的计算依赖检查，只证明路径确实接通，不据此声称跨语言机制有效。

输入仍是原 `torchaudio.load` + `data.pad(64600)`，不重采样、RawBoost、加噪、重采样类别或研究顺序。两分支接收同一 tensor。

## 8. 单候选最小实验

seed20，复用保留的共同冻结预热 3 轮 SLS 后端与 RNG。任务 SSL 从原始权重初始化，**不从已经特化的 epoch10 SLS 初始化**；无新预热、无重新跑 SLS、自参照或其他方法。

预热文件只存 backend/RNG，不存 SSL 或优化器：保持旧臂相同设置，新建 AdamW；不是精确续训。原始资产路径：

```text

models/SLS_conditional_residual_seed20/warmup.pth
```

预期 SHA 沿用已有 config，正式加载时必须重新核验；本轮仅确认文件存在，未重新计算大文件 SHA：


源集25380条，真2580/假22800，逐完整 epoch 校验计数。仅运行总 epoch4至8，共5轮新的微调。沿用 batch16、eval16、workers4、BF16、head/SSL lr均1e-6、AdamW weight_decay1e-4、foreach=False、clip5，SSL eval 关闭原有 dropout/layerdrop/masking但仍反传，后端正常 train。

- ITW比同阶段 SLS差超过3个百分点，且四跨语均值无改善；
- 任一跨语域EER>35%，且比同阶段 SLS差超过8个百分点。

若通过，后续两个种子需各自3轮冻结预热，不复制seed20后端冒充独立种子；使用相同方案、预算和源选权重。三种子全部逐域报告，记录跨种子均值、标准差、最坏种子、差距及任何严重失败。仅3种子不证明任意种子均有效。没有可核验的对应纯SLS多种子对照时，不称已证明相对SLS种子方差下降。

论文SLS/Mamba整行是外部参照，不拼接两模型逐域最佳。不将仅改善自家弱对照等同研究成功。不通过就分析此具体失败，不自动扫系数、加门控、换头、挑种子或继续后台试验。

## 11. 实施判断

**可以开始实现这个单候选最小版本。** 理由是它直接改变原始跨语言表示与任务适配的交互位置，保留全宽SLS和大量可训练任务能力，具有清楚的已有方法依据、可对照的阶段指标与可控成本；不需要再加入模块才能定义完整模型。

这不是“注意力原因已经查明”或“方法必然成功”的判断。实现后必须通过初始化等价/外部Query路径/梯度/资源检查，再进行一次seed20的真实效果筛选。目前仍无本方案实验结果。
