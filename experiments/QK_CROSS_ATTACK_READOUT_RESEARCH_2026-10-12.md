# 原始Q/K下的判据迁移：解析源组读出研究

日期：2026-10-12。状态：阅读原始论文、项目旧报告及代码，完成CPU合成数学核对；没有SSH、读取远端权重、训练语音模型或改变监控。此为可实现的研究候选定义，不是已验证改进，也不是正式训练启动指令。

## 1. 收敛到什么问题

原始Q/K继续提供实际冻结的24层A0(x)，V/out/FFN等维持基线可训练范围。研究问题为：除当前后端能拟合英语真假外，骨干是否提供能从一种源生成机制迁移到另一种机制的真假判据？

现有结果只支持源拟合不能区分迁移效果，未定位到FFN损坏、内容捷径或攻击记忆。本文不恢复冻结FFN主线，不将源攻击迁移等同跨语言迁移。

一个竞争解释是：预训练路由组织了可迁移的上下文，但分类后端与骨干可以协同选择对源集有效的不同线索。不同种子选择不同线索，迁移表现因此不同。这是可检验假设，不是已证实原因。后端本身和独立预热也可能参与波动。

## 2. 已有方向不能换名重提

- 旧RP已定义真实语音的教师时间关系保持，第4轮早期负结果、最终资源中断。真实类选择性蒸馏不是本轮新思想。
- PSR、条件残差、ReferenceValue等不能因为加入一个不同距离就重新视为全新方向。
- 旧攻击迁移稿已提出WORLD/非WORLD分组与MLDG；其内步尺度、BF16虚拟位移、源NLL饱和、SLS BN和更新次数尚有问题。本文不直接启动该稿，也不将它写成正式失败实验。
- 全局去攻击信息和把伪造全部拉成一个簇，可能删除有效的伪造线索，不是所需的判据迁移条件。

## 3. 原始研究支持哪些部分

1. [Generalizable speech deepfake detection via meta-learned LoRA](https://arxiv.org/html/2502.10838v2)报告相同rank16适配容量下ERM与MLDG的跨语料表现、种子方差不同。这支持研究监督目标；其Q/K可训练、AASIST及训练协议与本项目不同，不能照搬成绩或内步。
2. [Meta-learning with differentiable closed-form solvers，ICLR2019](https://www.robots.ox.ac.uk/~vedaldi/assets/pubs/bertinetto19meta-learning.pdf)提出通过解析岭回归读出反传学习表示。解析求解和域外读出监督已有先例，原实验是视觉少样本学习，没有证明本项目跨语言有效。原文还学习读出缩放等超参数；本候选不学习这些缩放。
3. [Not All Attacks Are Learned Equally in Speech Deepfake Detection，2026预印本](https://arxiv.org/html/2609.11763v1)发现汇总训练量/损失不能充分描述不同攻击对边界的影响。本文不采用其攻击曝光、课程或重放调度；只据此保留攻击级解释的必要性。

候选的价值只能通过实验建立：固定多语言预训练关系下，额外监督骨干的源机制间可读性是否改善跨语言检测及固定种子表现。不能宣称解析元学习、攻击分组或二者组合本身是新贡献。

## 4. 候选定义：跨源机制的解析读出损失

令phi为原始Q/K方案中可训练的XLS-R骨干参数，psi为原SLS后端参数。分类前向、原始A0、参数集合及优化器全部沿用基线。

从骨干的原生24层状态H_l(x)构造仅供训练损失使用的固定统计：

    u_l(x) = concat(mean_t H_l(x), std_t H_l(x))
    r_l(x) = u_l(x) / max(||u_l(x)||, epsilon)
    r(x) = concat(r_1,...,r_24) / sqrt(24)

每个正常非退化样本||r||=1；epsilon固定1e-8，std采用总体方差平方根并作数值保护。此统计为49152维，不改变后端实际收到的24层201×1024状态。均值/标准差是一个明确的辅助读出选择，不声称保留全部帧顺序或覆盖全部伪造证据。

源机制分组沿用旧可行性稿的单一划分：

    S_fake = A02/A03/A05 (WORLD)
    T_fake = A01/A04/A06 (非WORLD)

两侧各有两种TTS、一种VC，均包括真实语音。真实ID以预定SHA256首位划入两侧，ID不重叠；真实语音不赋予声码器标签。不假定真伪文本配对。两侧任一不足2条真实或没有伪造时，跳过辅助项，正常源训练照常完成。

对于支持组S，令y为真实+1、伪造-1，c_i为原真实0.9/伪造0.1权重在S内归一化后的系数。定义一个无截距的临时线性读出：

    w_S = argmin_w sum_(i in S) c_i (r_i^T w-y_i)^2 + rho ||w||^2
        = (R_S^T C_S R_S + rho I)^(-1) R_S^T C_S y_S

实际实现应使用线性方程求解，不显式计算逆矩阵。采用对偶形式只需求解|S|×|S|矩阵；r维度不需要压缩。rho固定1，不学习尺度、不采用放大logit的温度或乘数，不做rho网格。

用这个读出在另一组T上计算真假交叉熵：

    L_(S->T) = sum_(j in T) c_j softplus(-y_j r_j^T w_S)
    L_transfer = (L_(S->T) + L_(T->S))/2

支持组表示通过解析解影响w，查询组表示通过预测影响损失；两条路径都对phi反传。不能detach w后声称完整优化此目标。此读出是训练期辅助分类器，没有持久可训练参数或独立Adam状态；不能笼统称“没有辅助分类器”。它不参与评估、不用于替代SLS，也不接受目标语言数据。

辅助损失不依赖psi。原SLS只接收正常源NLL；V/out/FFN等骨干接收正常NLL与辅助项。换MLP/Mamba时可沿用同一骨干损失定义，但跨后端效果仍须各自匹配实验验证。

这项定义不强制两种伪造拥有同一特征向量，也不分类攻击ID；它要求一侧拟合出的真假读出在另一侧有效。优化仍可能压低攻击特有变化，不能声称它保证保留全部攻击信息。

## 5. 与原始Q/K和多语言动机的关系

原始A0参与产生任务状态，是模型计算的一部分；它不进入源组标签或解析求解器，也不提供真假答案。学习目标测试的是在这些预训练关系组织出的表示中，真假证据能否跨源生成机制读出。

这比“多冻结一些参数”更直接地约束任务学习，但并没有排除两源组共用的英语、静音、说话人或录音捷径。A0本身也可能编码这些因素。仅英语源分组无法识别所有未见语言的条件分布。

因此如果候选有效，至少还需分辨额外线性监督、真正源机制留出和原始A0的作用。后续可作同成本混合机制划分对照，并在匹配协议下比较该辅助目标有/无原始A0。当前不启动这些多臂训练；也不预先将组合收益称为多语言知识利用的因果证明。

## 6. 源NLL饱和：解决了什么，没解决什么

临时w每次根据当前源组重算，不继承后端的大margin。归一化r、sum c=1、y=±1时，令X=sqrt(C)R和v=sqrt(C)y，有||v||=1。由sigma/(sigma^2+rho) <= 1/(2sqrt(rho))：

    ||w_S|| <= 1/(2sqrt(rho))
    |r_j^T w_S| <= 1/2  (rho=1)

因此查询CE不会仅靠无界放大读出权重趋零，范围为softplus(-0.5)到softplus(0.5)，约0.4741到0.9741。这是带归一化、固定rho、无截距/缩放条件下的界，不能套到原SLS或任意岭回归定义。

**非零损失不等于有效骨干梯度。** 若两组归一化特征全部塌缩、类别权重平衡，可以w=0、loss=log(2)、总表示梯度却为零。完全反向的两组特征也可因球面归一化落在驻点。普通NLL仍有必要，不能称源饱和问题已经解决；开跑前只需短源批确认实际辅助梯度可测，不开展大规模探针或寻找放大系数。

## 7. 完成的CPU合成核对

脚本：`tools/analyze_qk_cross_attack_readout.py`；结果：`QK_CROSS_ATTACK_READOUT_MATH_2026-10-12.json`。只用NumPy合成向量，没有语音、权重、真实模型或EER。

- 包含支持解导数及输入归一化链式导数的梯度与中心有限差分最大误差1.3246e-10；随机例支持/查询梯度均非零。
- 同方向跨组判据损失0.474077；两组完全不同方向的判据损失0.693147，合成例两侧都有梯度。
- 将同方向线索解释为真正伪造证据或共享源静音捷径，目标与梯度完全相同。这是反例，不是语音上的捷径测量。
- 平衡塌缩例loss0.693147却无有效梯度；反向例loss0.974077也可为归一化驻点。
- 不同伪造模式在共享判据下可以获得较低损失；这不证明训练不会压低其中差异。

这些核对只证明目标实现和局限可明确描述，不支持预测真实实验会获益。

## 8. 保持batch16和原AdamW步数的实现边界

正常源loader、自然比例、batch16、每轮1587个正常更新、音频处理和源NLL全部保留。不把128条累积成一次正常更新。

一个固定工程定义：暂存当前连续8个正常batch的波形/ID；每到第8个batch，在当前phi上使用这128条进行一次辅助计算，把L_transfer以系数1加入该次正常更新。其余7次只有正常源NLL。没有额外optimizer.step或内循环。源末尾不足8批的余块仅作正常源更新，不补抽样。此为稀疏辅助监督，不能声称等同于每个batch加入完整同权重辅助目标。

为控制24GB显存，先在同一phi下无梯度得到块内固定统计，解析求解并对统计求导，再逐microbatch重算骨干，把统计梯度通过VJP加回phi，最后与正常NLL一起使用原clip5和一次AdamW更新。若期间phi不变、两次骨干计算相同，此链式梯度等价；这里不使用陈旧特征队列近似支持梯度。真实GPU一致性/耗时还未测量。

辅助路径不运行SLS，不更改SLS BN；骨干保持原eval模式以关闭dropout/layerdrop而保留梯度。额外计算仍需维护原RNG约定。额外访问是重算固定源块，必须披露计算成本和访问量，不能称完全没有重复读入。

源选权重仍按完整正常分类NLL，不用含固定正下界的辅助总损失，也不使用目标表现或源留出读出loss选checkpoint。

rho=1、块128、每8次一个辅助项、系数1、固定统计、WORLD分组均为首次检验的单一候选定义，不是被文献证明最优的设置。若真实源梯度无信号或成本不合适，应报告当前候选不具备开跑条件，不自动改变尺度/温度/rho/分组来追目标成绩。

## 9. 可推翻的预测与实验决策

若进入实验，先固定seed20、相同原始权重及自身三轮后端预热、正式4–8、阶段4/8完整五域。新方法不从失败UnitMass权重继续训练，不自动扩种子。

1. 若源机制间的读出差距下降且五域整体改善，才有理由继续固定1001/7与后端验证；单seed不是稳定性证明。
2. 若源读出变好而跨语言仍差，当前源机制迁移代理不足；不能提高系数后把它称作同一成功假设。
3. 若辅助统计变好但原SLS检测变差，可能是线性统计偏置/目标冲突；不改后端救此候选。
4. 若骨干源判据原本已经稳定、主要波动来自后端或预热，则本候选的机制动机应下调；当前未做定位，不能假定相反。
5. 即使跨语均值改善，最坏域严重失败、ITW明显退化或固定种子效果不一致仍不满足目标。

当前结论：已形成一个可实现、可证伪的骨干损失候选，解决了旧MLDG稿需要虚拟骨干内步这一特定障碍；没有证明跨语言性、创新性或有效性。只进行了CPU合成数学核对，未启动语音实验。
