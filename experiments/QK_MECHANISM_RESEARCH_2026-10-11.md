# 从原始Q/K的收益研究可迁移的伪造判据

日期：2026-10-11。性质：现有记录复核、保存分数再分析及原始论文研究。没有启动训练、模型推理、远程连接或修改模型/优化器。本文取代同日 `XLSR_QK_VO_ONLY_RESEARCH_2026-10-11.md` 中将冻结FFN列为优先下一候选的建议；保留旧文作为思考记录。

## 1. 当前判断

原始实际Q/K是值得保留的实验发现，但目前尚不能把收益的机制写成“保留了多语言知识”。下一步的首要研究问题应是：**原始语音关系是否让模型按语音上下文解释伪造异常；不同种子是否学到了不同的上下文依赖判据？**

这是有依据的工作假设，不是已得到验证的新方法。其竞争解释是：原始关系主要提供固定的聚合结构，限制源域过拟合，而不必依赖跨语言语音知识。还有第三种可能：骨干已有可迁移信息，种子差异主要来自SLS读出。只比较最终EER不能区分三者。

用户限定的研究对象是XLS-R适配机制，应能用于MLP/Mamba等后端。保持源数据、预热、优化器及评估规则；不用目标数据训练或选择候选，不把随机种子平均当成方法。架构上能接其他头，并不能代替跨后端实验有效性的证据。

## 2. 本次得到的新证据

### 2.1 收益包含同组内真假排序改善

对 `models/UK_query_localization_seed20/scores.csv` 的9709条UK保存分数重新计算AUC。该记录来自Query seed20 epoch8的固定权重端点干预，不是三个当前原始Q/K训练种子的结果。

标签1是真实，较高分数对应真实；并列分数按0.5计。全局AUC复现原报告，说明方向和计算一致。分组是CSV已有的朗读者/书籍路径，共13组。

| 成对比较范围 | 原Query实际路由 | 替换为实际原始Q/K路由 |
| --- | ---: | ---: |
| 全部真假对 | 0.876294 | 0.937689 |
| 同组内真假对，加权 | 0.897840 | 0.948778 |
| 不同组之间真假对，加权 | 0.872957 | 0.935972 |

同组AUC有12组提高、1组降低。所有真假对共23,545,000个，其中同组3,157,439个。加权按各组真实数×伪造数，不能用未加权组均值替代全局分解。

因此可排除“收益完全只是组间分数偏移或每组严格单调校准”的解释：这种改变不会提高组内AUC。不能排除组内的录音、生成器等混杂，也不能直接确认音素机制。成对比较不是独立样本，不能把两千多万对当成统计样本量。UK已参与研发，不是盲测。

详细结果：`QK_SAVED_SCORE_REANALYSIS_2026-10-11.json`。源CSV SHA256：`46d0d75538a514e4f40cec5b220ce06233ecafaa3304f162ddae44d78084ff8e`。

### 2.2 平均关系漂移不是足够的失效解释

汇总同一Query端点的 `layer_diagnostics.csv`，KL方向为 KL(当前Query关系 || 原始实际Q/K关系)，每层先对样本、头及8个固定query位置平均，再对预定层段等权平均。2026-10-11后续核对代码发现：query位置取 `linspace(0,min(200,T-1),8).long()`，不是全部帧；表中数值不变，但解释限于这一稀疏诊断。

| 样本 | 1–8层平均KL | 9–16层 | 17–24层 |
| --- | ---: | ---: | ---: |
| 英语源伪造 | 0.014173 | 0.453470 | 1.638682 |
| 英语源真实 | 0.007559 | 0.203412 | 0.649656 |
| UK伪造 | 0.007452 | 0.221772 | 0.781476 |
| UK真实 | 0.006235 | 0.172794 | 1.014779 |

源伪造后部平均漂移超过UK伪造，但源1024条已见训练样本端点EER仍为0。因此“漂移越大，检测越差”不足以指导设计。这里源样本并非独立验证集，不能据此宣称源泛化很好。

UK真实后部熵均值只从原始0.712283变为0.708014，而KL达到1.014779：相近的平均熵并不意味着关注相同帧。仅用尖锐/平滑解释同样不足。数值见 `QK_LAYER_DIAGNOSTIC_REANALYSIS_2026-10-11.json`。

### 2.3 现有结果限制了哪些故事

- 恢复Query端点原始路由使UK EER 21.2173→13.8017，同时ITW的1024条子集8.0043→12.3963。不是普遍改善；子集不能冒充全ITW。端点替换会改变后续所有层激活，不是训练过程中的独立模块因果消融。
- 当前原始Q/K三个种子的epoch8 UK分别15.2643/17.5611/22.0827。教师关系对相同音频固定，但任务特征与读出不固定。这定位了仍可变化的路径，尚未定位种子不稳定的故障模块。
- seed1001从4到8五域均改善，不能把所有种子差异解释成统一的晚期遗忘。
- 旧纯SLS诊断中，UK标签训练的探针能读出微调后真假信息，但英语训练探针转UK明显恶化。它支持“可读信息与可迁移判据不同”，也可能读到数据混杂；该模型不是当前Q/K模型，不能合并成同一次机制实验。

## 3. 原始研究如何改变问题表述

### 3.1 多语言能力不等于消除语言信息

[Self-Supervised Speech Models Encode Phonetic Context via Position-dependent Orthogonal Subspaces，2026](https://arxiv.org/html/2603.12642v1) 研究帧级表示，发现当前及相邻音素的音系特征可按相对位置编码。主要分析WavLM及其他语音模型，不是当前XLS-R原始Q/K的直接验证。

[Analyzing the relationships between pretraining language, phonetic, tonal, and speaker information in self-supervised speech models，2025](https://arxiv.org/html/2506.10855v1) 对不同语言预训练的单语wav2vec2进行探测，说明语音表示可携带跨语言可读的音素信息，同时有训练语言相关差异。研究对象不是多语言XLS-R；不能将其层定位直接移植到24层模型。

这支持把上下文视为可能有用的条件，而不是默认必须删掉的内容。发音类别、共发音及韵律会改变正常声学模式；检测可以在这些条件下判断异常。它不要求所有语言的整体特征分布相同。

### 3.2 伪造线索可能依赖音素上下文

[PhonemeDF，2026](https://arxiv.org/html/2603.15037v1) 使用英语平行真实/合成语音，观察到音素类别、合成系统及表示类型影响真假可分性。其范围限于英语、有限生成系统和分类设置，不能据此证明跨语言条件不变。

研究启发是：应区分“上下文出现频率不同”与“同上下文的真假条件分布不同”。若C表示语音上下文、L表示语言、H表示检测特征，则

    p(H | Y,L) = ∫ p(H | Y,C,L) p(C | Y,L) dC.

即使不同语言的边缘分布不同，条件判据仍可能部分共享。但这要求验证 `p(H | Y,C,L)` 的稳定性；共享音素本身不保证共享伪造痕迹，生成器和录音条件也会改变它。

### 3.3 保留注意力分布不等于保留完整关系知识

[MiniLM，2020](https://arxiv.org/html/2002.10957v2) 的消融显示，蒸馏QK注意力之外的Value关系有额外收益，Value关系蒸馏优于其直接Value MSE对照。作者还报告隐藏状态关系迁移对不同教师表现不稳定。它研究文本模型压缩，不能作为XLS-R检测配方。

[MiniLMv2，2021](https://aclanthology.org/2021.findings-acl.188/) 扩展到QQ、KK、VV关系及XLM-R。最终主要转移三种自关系，并非同时使用全部九种；教师层的选择也影响结果。这使“固定QK等于完整保留多语知识”的说法更站不住脚，但直接照搬VV损失仍缺任务依据。

[Attention Transfer，2024](https://arxiv.org/html/2411.09702v1) 区分注意力与Value，并讨论注意力头可重新分配而完成类似功能。它的视觉OOD结果也说明注意力迁移不能保留完整微调模型的全部OOD优势。不能只比较头平均注意力图，便断言模型使用了相同知识。

### 3.4 必须保留反面证据

[Language Orthogonalization for Zero-Shot Cross-Lingual Audio Deepfake Detection，2026](https://arxiv.org/html/2609.16458v1) 在SEA-Spoof用真实源数据拟合外部语言识别表示到冻结语音特征的映射，语言去除总体有收益。但表2单语言训练的XLS-R近语言组EER由3.33变为4.05，远语言组11.72变为9.18。

所以“删语言一定错”和“保留语言一定对”都不成立。该研究的冻结特征、外部LID、多种源语言组合与当前约束不同；平均收益不能抹掉条件性退化，也不能推断因果语言距离。

## 4. 下一步应检验的主假设

优先研究：**利用原始语音上下文，学到在相似发音关系下可共享的伪造响应，而不是继续要求任务表示整体更接近教师。**

可能的机制链条为：多语预训练提供可迁移的上下文组织 → 英语真假监督学习上下文内的异常响应 → 在其他语言共享或相近的发音条件下迁移。种子不稳定可能来自英语训练对不同条件下异常线索的选择不同。最后一环尚无跨种子中间证据，不能先写为事实。

这比“固定关系后Value还会漂移”更具体；后者已经是旧Neighborhood实验的动机和导数分析，不应重新命名为贡献。

### 三项有区分力的研究检查

1. **原始关系究竟组织什么。** 使用预定的低/中/高层段，核对关系与音素类别/边界、局部时距、说话者及静音等的联系。上下文代理应从冻结原模型获得，且独立验证；教师均值余弦或无监督聚类不能直接叫音素。伪造上形成的聚类也可能只是生成器聚类。若有语音标注，只作源域诊断，不能让目标标注进入训练或选择。
2. **真实内容匹配是否重要。** 在固定模型端点进行保持注意力统计的关系错配对照，再与正确对应关系比较。例如 `P A0 Pᵀ` 配合未置换的Value可保留熵多重集和谱；时间反转P还保留全局绝对时距权重分布，但破坏关系与任务帧的对应。它不保证逐query时距统计不变，反转对称的局部A也可能几乎不变，必须测量实际干预强度。若正确对应关系没有优势，应降低语音语义解释，转向固定聚合结构解释。这是推理诊断，不是再做扰动训练。
3. **不同种子偏向哪些条件，以及信息在哪里丢失。** 固定条件定义后，比较各种子骨干内真假响应、原始关系的有效消息及最终分数；在不参与拟合的英语上下文/说话者/攻击组检查泛化。仅按英语源拟合统一的小读出作为诊断，若骨干指标稳定而原SLS不稳定，优先判定读出耦合；若骨干响应已不稳定，才有理由研究骨干条件约束。换诊断读出不等于已验证MLP/Mamba迁移。按上下文划分时也必须核对类别/攻击覆盖，避免把攻击差异误当成上下文差异。

权重已按清理要求删除，本次只能完成保存记录分析。以上需要模型权重的检查是后续授权实验中的诊断内容，不是本次完成事实。不能自动重训来补齐，也不能通过目标反馈挑层/头。

## 5. 如果主假设得到支持，方法应该约束什么

研究对象应放在XLS-R内部任务特征的条件响应：在可靠、冻结的语音上下文条件下，限制真假适配依赖具体源说话者/生成器的程度，并保持真实语音条件结构。推理继续输出标准XLS-R层表示，后端可独立更换。

目前不指定新的损失权重或训练配方。首先缺的是可靠条件变量，以及条件内真假响应可迁移的证据。直接拼接教师特征、给每种音素加分类头、压缩到统一真假簇或新增一个蒸馏项，都不能自动解决这个缺口。

尤其不能假定原模型是“纯真实语音先验”：SSL教师对合成痕迹也可能敏感；匹配全部伪造样本的教师几何，可能限制必要的任务学习。仅真实样本关系约束也已在旧RP中提出，不能称为全新方向。

### 与已尝试方案的边界

| 旧方案 | 对新研究的约束 |
| --- | --- |
| ContextContrast：教师整句均值/余弦加权FC1 SupCon | 已失败。它没有验证音素条件，混合了多种上下文信息；但不能仅换成“音素”名称再加对比损失。必须证实条件和响应对象不同。 |
| Difference / Variation | 已试聚合残差或平方变化。`V-A0V`不自动等于伪造异常，不能作为新方向重提。 |
| ReferenceValue / ValueIncrement | 恢复或保留教师Value的具体路径失败，反对“越接近教师越好”的简单推断；不证明所有功能保持无效。 |
| Neighborhood / BoundedRelation | 限制或扰动关系未改善整体最终结果；无根据再做关系半径/强度网格。 |
| PSR / 内容对抗 | 大方差子空间或CTC代理不等于已识别的纯内容。不能先删掉有用语音条件再解释收益。 |
| RP_temporal | 真实样本隐藏状态时间Gram保持已设计，运行中断不能当科学负结果。MiniLM式关系思想也不是此项目独创。 |
| 冻结FFN / FFN慢学习率 | 当前没有故障定位，前者不列为首选，后者也不符合用户研究范围。 |

## 6. 可以写入论文与尚不能写入论文的结论

现在可写：在既定协议下，原始实际Q/K提供有价值的迁移参照；UK端点收益包含同朗读者/书籍组内的排序改善；简单关系漂移量或熵不足以解释差异；原始Q/K仍有跨种子和跨域取舍。

现在不可写：已经证明保留了跨语言音素知识；已经确定FFN导致遗忘；已获得与后端无关的稳定方法；任何语言都受益；已排除生成器/语料混杂；已证明音素条件下伪造规律语言不变。

下一轮有价值的结果应能区分上面的竞争解释，并给出能被否定的机制预测。若语音上下文解释不成立，应明确放弃它，而不是继续在其名义下堆叠正则项。
