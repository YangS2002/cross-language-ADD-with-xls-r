# 固定原始Q/K后的源攻击迁移：分组、学习信号与实现可行性

日期：2026-10-11。接续 `SLS_QK_ATTACK_INFORMATION_RETHINK_2026-10-11.md`。

状态：本地文献核查、代码阅读、数学推导和CPU合成计算。未实现候选、未SSH、未运行GPU诊断、未训练或改变监控。历史交接中的停止与清理状态仍按原记录理解，本轮没有远端实时核验。

## 1. 本轮判断

源攻击信息值得继续研究，但“随机划分A01–A06并加入MLDG”还不足以成为可开跑的方法。新的具体进展有四项：

1. 六个攻击ID不是六个独立声码器。按生成机制分组，比任意ID分组更能定义一次有意义的源内分布变化。
2. 元目标需要证明改变了骨干更新；辅助NLL非零或合成自检通过都不够。一阶近似、AdamW内步及源损失饱和必须分别处理。
3. SLS BatchNorm和每物理batch的加权NLL归一化，使分组不再是免费的实现细节。
4. 128条逻辑块可以改善真实样本不足，但直接每块更新一次会将优化器步数减少近八倍，不能混同于原batch16协议。

本轮收敛为一个待检验研究候选：保留实际原始A0，按生成机制构造两侧源组，只在任务XLS-R可训练骨干上模拟虚拟更新，检查另一组真假风险与骨干梯度相对于未虚拟更新状态的变化。SLS结构和正式源分类训练保留。尚未确定内步、辅助强度及可接受开销，不宣称可以直接付费训练。

## 2. 六个ID到底提供什么信息

根据ASVspoof官方Interspeech2019介绍中的攻击表：

| 攻击 | 类别 | 声学模型 | 波形生成方式 |
|---|---|---|---|
| A01 | TTS | VAE + AR LSTM-RNN | WaveNet |
| A02 | TTS | VAE + AR LSTM-RNN | WORLD |
| A03 | TTS | Feedforward NN | WORLD |
| A04 | TTS | — | 波形拼接 |
| A05 | VC | VAE | WORLD |
| A06 | VC | GMM-UBM | 谱滤波 |

来源：[ASVspoof官方介绍，第15页攻击表](https://www.asvspoof.org/interspeech2019_slides.pdf)；[数据库原论文](https://arxiv.org/abs/1911.01601)。表格不能推出不同系统只有声码器这一个因素变化。

如果均匀选择3个ID为S，另外3个为T，共C(6,3)=20个有方向划分。只有WORLD三个ID恰好全在S或全在T的2个划分不共享WORLD；其他18个两侧均有WORLD，即90%。这是组合计算，不是已有训练日志的实测分组频率。这个结论只针对3对3划分，不泛化到所有元学习划分方式。

因此，一个更明确的单次分组候选是：

- WORLD侧：A02/A03/A05。
- 非WORLD侧：A01/A04/A06。

两侧均为两个TTS系统加一个VC系统；按已记录的每攻击3800条，伪造总量各11400。全源真实2580条分为不重叠两份时，可使两侧总量及真假比例接近。真实样本没有对应的“WORLD真语音”标签，不应人为赋予这种含义。

这能减少共享波形生成家族造成的弱划分，也控制了粗粒度TTS/VC组成；不能严格隔离声码器因素，非WORLD侧包含三种不同机制，仍可能有共同录音、静音或其他捷径。它模拟的是源生成机制变化，不是语言变化。

真实样本应按预定ID规则不重叠划入两侧，尽可能控制源说话人组成；不能假定真伪同说话人等于同文本或帧对齐。本轮没有读取远端完整协议核验逐ID/说话人分配，该步骤仍未完成。

## 4. 一阶近似到底省掉了什么

先在平滑、确定性、普通SGD内步的理想条件下，令：

    gS = grad L_S(theta)
    theta' = theta - alpha gS
    J = L_S(theta) + beta L_T(theta')

记H_S为L_S的Hessian，gT'为在theta'处计算的目标组梯度。精确梯度为：

    grad J = gS + beta (I - alpha H_S)^T gT'

常用的一阶近似是：

    g_FO = gS + beta gT'

它省掉 `-alpha beta H_S^T gT'`。在局部展开中：

    grad J ≈ gS + beta gT - alpha beta (H_T gS + H_S gT)
    g_FO   ≈ gS + beta gT - alpha beta H_T gS

因此，直接称一阶实现“精确优化跨组梯度对齐”不成立。另一种错误是对当前参数梯度做detach后计算点积，再声称点积项在训练：两侧都detach时，该点积对参数没有梯度。

CPU二维平滑二次函数验证：

    H_S = [[2, 1], [1, 3]], b_S = [0.2, -0.3]
    H_T = [[4, -0.5], [-0.5, 1]], b_T = [-0.4, 0.6]
    theta = [0.3, -0.2], alpha = 0.1, beta = 0.7
    L_k(theta) = 0.5 theta^T H_k theta + b_k^T theta

精确梯度 `[0.929, -0.4775]`；中心有限差分最大误差约3.10e-11；一阶近似为 `[1.041, -0.362]`。这只验证推导，未读取源音频或验证BF16、真实模型梯度和性能。XLS-R/SLS含maxpool等非光滑操作，以上推导还需要局部可微条件，不能当作整网全局定理。

## 5. 内步不能直接复制外部AdamW学习率

原训练器是AdamW，lr=1e-6，wd=1e-4，梯度全局裁剪5。普通SGD虚拟步 `-alpha gS` 与AdamW的动量、预条件及解耦衰减不同。

若将alpha也取1e-6，并对支持梯度同样裁剪至5，则SGD虚拟位移的欧氏范数最多5e-6；这个事实本身既不能证明无信号，也不能保证有信号。BF16前向下，需要实际核对参数位移、logit变化及目标组梯度变化，而不是只看内步执行成功。

若模拟AdamW，必须定义虚拟动量状态、是否含weight decay及bias correction，并且不修改真实优化器状态。衰减导致的目标风险变化还不全来自跨组判别梯度。若只借用冻结的预条件矩阵P，局部内步为 `-alpha P gS`，对应相互作用是 `gT^T P gS`，不再是原始欧氏点积。P如果依赖支持梯度且参与求导，还会出现额外导数项。

现有资料没有给出合理的内步尺度。本轮不通过任意放大alpha、归一化近零梯度或引入第二种辅助损失来制造信号。

## 6. 源近零NLL为何仍是核心风险

三个seed第8轮日志中的exact_weighted_nll分别为：

| seed | 第8轮在线精确加权聚合NLL |
|---|---:|
| 20 | 2.1471682280e-6 |
| 1001 | 2.2710393026e-6 |
| 7 | 1.7660066902e-6 |

这些是一个epoch内不断变化的模型产生的在线训练统计，不是最终固定模型重新计算的各攻击组风险。不能据此说已经测量了组梯度、虚拟更新响应或最终每组风险。

对单样本二分类正确margin s，CE为softplus(-s)，其margin导数绝对值为sigmoid(-s)，并且：

    sigmoid(-s) <= softplus(-s)

因此，低CE约束了对应输出层面的梯度信号；参数梯度还乘模型Jacobian，没有Jacobian界时，不能直接断言骨干梯度必然同样小。组内困难样本和AdamW状态也可能产生非平凡变化。

在假设某个固定模型的全源精确加权风险为L时，总权重为：

    2580*0.9 + 22800*0.1 = 4602

每攻击伪造组的权重质量为380/4602，风险非负意味着该组均值风险最多 `(4602/380)*L ≈ 12.11L`。这说明重新按六个完整攻击组取最大风险不能无限放大信号；该界不能套用在线epoch日志，也不界定小块抽样的组风险。

更根本的反例：假如两个源机制组都共享“某个静音统计与真假一致”的线索，依赖这条线索的更新可以同时改善两组，而目标语言不再共享这个关联。源内梯度协调与跨语言判据有效之间仍有缺口。原始A0也不能提供真假真值来排除这个解。

## 7. 真实样本支持：逻辑块能解决多少

按全源25380条、真实2580条，不放回均匀shuffle，块中真实数服从超几何分布。CPU直接用概率递推计算：

| 逻辑块条数 | 真实期望数 | 真实不足4条的概率 |
|---|---:|---:|
| 16 | 1.6265 | 92.8206% |
| 64 | 6.5059 | 9.8671% |
| 128 | 13.0118 | 0.0660% |

“至少4条”仅表示能给两侧各分至少2条不同ID的真实语音，不表示梯度估计已可靠，也不保证说话人平衡、两侧伪造覆盖或每个物理microbatch有两类。这不是实际种子loader的重放结果。

128可以作为一个待审阅逻辑块大小，物理batch仍16；不足真实或某侧无伪造时跳过辅助部分，保留全部正常源NLL，不额外抽真实样本、不复制同一ID充当两侧样本。

## 8. 加权归一化与BN不是可忽略的细节

### 8.1 每物理batch的NLL与合并大batch不同

当前每物理batch的损失为 `sum_i w_i ell_i / sum_i w_i`。K个batch在同一参数处等权累积，得到的是这些比值的均值；先合并K批再统一除总权重，一般得到不同目标。

合成例：两个batch各16条，分别1真/15假、3真/13假；所有真实NLL设2、伪造NLL设0.1。物理batch损失均值为1.0975，合并后加权NLL为1.16875。计算只说明归一化差异，不是真实训练结果。

如需在同一参数状态下保持块内原物理batch目标，应保留每个原batch的分母，定义：

    c_i = w_i / (K * W_b(i)), W_b = sum_(i in b) w_i
    L_block = sum_i c_i ell_i

分组后的贡献仍使用c_i；不能对各组重新各自归一化后直接相加并声称主目标不变。支持梯度若单独归一化，还需显式记录它的尺度。

即便这个目标相同，原协议每批更新一次，累积协议K批才更新一次，模型状态序列和AdamW状态仍不同。

### 8.2 当前Q/K模型确实使用训练态SLS BatchNorm

当前前向是任务状态→未detach层门控→first_bn→SELU/maxpool→FC分类；SSL eval并未让SLS BN自动进入eval。拆分支持/查询batch会改变BN输入统计，从而即使参数没更新也可能改变分类输出。

辅助比较必须为同一查询microbatch计算更新前、更新后的匹配结果；两边采用相同的BN/RNG处理规则，且虚拟支路不能修改真实模型running statistics。可以使用独立buffer副本，但不能把复制buffer理解为“分类函数已与原混合batch完全相同”。

若冻结辅助BN统计，则需要披露辅助目标采用了另一种归一化条件。若使用查询自身batch统计，则需要披露目标以batch为条件，并保证前后匹配。当前尚未选择或验证这两种处理之一。

## 9. 把研究目标变成可检查的更新规则

令phi为原方案中可训练的任务XLS-R参数，psi为SLS后端参数。实际A0和任务Q/K保持冻结，正常分类训练仍更新phi和psi。虚拟内步只作用phi，避免一次支持组更新主要由后端重新拟合承担。

一个可继续推导的形式是：

    phi' = phi - alpha grad_phi L_S
    Delta_T = L_T(phi', psi) - L_T(phi, psi)
    J_phi = L_base(phi, psi) + beta Delta_T

更新前后L_T使用相同查询ID、损失系数、BN规则和RNG状态。alpha=0时Delta_T及其精确phi梯度应为0。这个检查有助于发现额外分类训练、buffer污染或分组归一化带来的伪响应。

如果辅助梯度只施加于phi，而psi只接收正常源NLL梯度，必须明确这是一条选择性更新规则，不声称对(phi,psi)联合精确优化同一个J。辅助SLS权重可以作为固定的可微函数传递输入梯度，不能把整个后端放在no_grad中截断骨干梯度。

对普通SGD内步，一阶更新差为：

    Delta_g_FO = grad_phi L_T(phi', psi) - grad_phi L_T(phi, psi)

它是虚拟更新后与更新前梯度之差，仍省略支持Hessian链式项，不是精确的Delta_T梯度。其作用强度、方向和稳定性都需要实际测量。它与普通MLDG目标也有区别，不能直接引用普通MLDG的实证效果。

这一形式旨在明确干预对象和匹配条件，不是为已有方法补写一个保证。它尚未作为正式候选定稿。

## 10. 更新次数与成本边界

每源轮原1587次AdamW更新。每128条只更新一次约199次，不能继续称“只加一个跨组约束、其他协议不变”。

一个保留主更新次数的工程草案是：原8个batch的正常更新照常；在第8次更新的当前参数状态，重新计算刚才逻辑块的支持梯度、匹配查询梯度及虚拟查询梯度，将辅助骨干梯度合入这次正常更新。其余7次只有正常NLL。最后不足8批的块也保留全部正常更新，是否有辅助由同一预定缺组规则决定。

这保留1587次主更新，但增加源样本访问和重新计算；不能称计算、梯度权重或全部参数轨迹与原训练等价。交替两个方向可避免长期只把一侧当查询组，但交替规则和强度仍待明确，不在目标域上选择。

平衡两侧时，支持、未更新查询、虚拟查询合计额外处理约1.5个完整块，叠加正常训练为约2.5倍任务样本前反传工作量。查询前/后可复用原始参照输入，原始参照的额外运行量与缓存策略有关；2.5不是实测墙钟倍率。

历史单源轮约310–320秒、两次五域评估约1150–1200秒。若源训练墙钟也达到2.5倍，五正式轮与两次评估已约84–87分钟，可能超过旧75分钟预算；不沿用原45分钟预计。更改预算需要另行审阅，不自动扩大。

内存量级：284246149个FP32参数组成一个向量约1.059GiB；这是整个可训练集合的量级，不等于准确的骨干虚拟参数量。额外梯度、原参数副本、虚拟参数、优化器状态和激活不能只算一项。缓存128条、24层、201帧、1024维BF16原始注意力输入约1.178GiB。当前wrapper在forward后清空参照输入，没有现成跨batch缓存；复用需另设计，不能假定已经支持。

以上没有24GB显存或耗时通过证据。二阶整骨干元学习不列为默认方案，也不通过增加Adam/教师全副本恢复状态来实现。

## 11. 正式候选之前还缺什么

只保留一个研究候选，不同时叠加margin、SAM、对比、攻击头或FFN减速。未来源域短自检至少需要回答：

1. 两侧真实/伪造及说话人覆盖是否符合预定规则，主样本和主更新次数是否保持。
2. alpha=0时匹配查询损失差和辅助梯度是否为0，实际原始Q/K关系是否始终保持。
3. 非零内步是否在既定BF16下产生可分辨的Delta_T和Delta_g；辅助信号相对正常骨干梯度有多大，而非只记录辅助loss。
4. 额外BN/RNG是否不改变真实状态，源loss下降后辅助信号是否迅速消失。
5. 短测的实测显存、样本访问次数、吞吐和保存峰值是否符合预算。

这些是实现和信号检查，不是跨语言有效性证明。有效性仍需要既定seed20单候选正式结果，完整列五域、四跨语均值/最坏域、CHDE与ITW，权重按最低完整源分类NLL选；之后才讨论固定1001/7。目标标签不用于内步、分组、强度或checkpoint选择；目标域已有研发使用必须披露。

现有小型记录没有上述组梯度和虚拟响应；历史正式best权重已按交接清理，不能声称可直接用这些权重补探针。本轮没有执行未来自检或开启训练。
