# 离线续析：从线性缩减到参照条件下的证据补充

日期2026-10-09。服务器关闭期间，只查阅本地模型及原始论文。没有SSH、模型实现、推理/训练、下载权重或恢复监控。本记录细化候选，不宣布目标达成，不是自动实验指令。

## 1. 修正上一份笔记的候选优先级

保留“原始XLS-R提供上下文参照、微调XLS-R学习伪造证据、SLS作为主体”的研究方向。将Z=H−0.5PH从既定下一训练方案降为被分析过的候选，不以其50–65分钟估计作为立即执行依据。

原因不只是没有实验结果，而是三个可在工程和数学上预见的缺口：

- P接近I时，Z接近0.5H。如果层门控不变，SLS的BN训练归一化会近似抵消这一共同缩放。eval还依赖运行统计；不能称任何情况下精确相同。
- 如果P为均匀矩阵U，且每层H=r+1μ、时间mean(r)=0，则Z=r+0.5×1μ。内容若在r中，依然存在；全局伪造若在μ中，反而一起削弱。没有依据将“均值”直接命名为内容。
- 固定P下I−0.5P可逆，任务路/后端有补偿空间。它可能改变优化偏好，但不提供内容独立性保证。

此外，SLS门控描述本身是各层时间均值。候选同时改变描述和分类values，结果改变可能来自层门控，而不是所声称的局部伪造证据。这不是两个实验模块，但在机制解释中必须区分。

以上不证明线性中心化必然无效；说明目前没有足够理由将它作为“内容削弱”方法直接付费完整训练。

## 2. 进一步收敛的研究假设

不要求整个任务表征与内容独立。语音上下文可能决定哪些声学变化正常、哪些异常。希望减少的，是未经上下文解释的绝对特征统计成为直接判据。

原始关系可以用于定义“哪些位置应一起被比较”；任务路保留学习真假敏感表征的自由。让SLS额外看到这些位置之间的声学变化模式，而不把全部上下文平滑成分强行删除。

相对于上一方案，这更符合用户的“原始层信息补充SLS表征”要求，也避免用全部冻结关系取代任务注意力、损伤任务适配能力。

这仍是工作假设。当前UK线性探针反对真假信息完全消失，但没有证明它来自通用声学伪造线索；实际QK收益支持关系有用，却没有证明原始注意力就是同音素图。

## 3. 新读到的相关论文与协议边界

### 3.1 语音上下文不只是时间平滑

[Self-Supervised Speech Models Encode Phonetic Context via Position-dependent Orthogonal Subspaces，2026预印本](https://arxiv.org/html/2603.12642)：分析英语预训练wav2vec2/HuBERT/WavLM，以及TIMIT、95语言VoxAngeles的语音学结构；单帧含当前与邻近音的组合性信息，并呈相对位置相关的近似正交结构。不同模型、层和数据存在差异。

借鉴：内容可能分布在复杂通道组合中，不能用时间均值或平滑程度直接识别。论文中的正交是不同相对音位置的结构，不是“语言内容与伪造痕迹正交”。它未验证当前微调XLS-R，因此不能直接移用其具体子空间。

### 3.2 音素条件下的变化模式已有直接检测研究

[Phoneme-Level Feature Discrepancies: A Key to Detecting Sophisticated Speech Deepfakes，AAAI2025](https://arxiv.org/html/2412.12619)：冻结音素识别路提供分组，复制Transformer学习任务特征，音素池化和GAT建模序列依赖；还使用语义对齐及音素替换增广。

其跨语言检测使用EN/DE/ES监督训练，音素识别器也以含UK等语言的Common Voice数据训练；不是当前英语单源协议。可借鉴“比较语音单位中的声学模式”，不照搬多语训练、GAT、对齐和增广整套组合，更不能将其成绩作为我们候选的预期成绩。

### 3.3 条件化而非全部去内容

[Phonetically Explainable Speech Deepfake Detection，2026预印本](https://arxiv.org/html/2606.15454)：区分音素存在权重与音素条件下的真假声学证据，采用显式假设得到可解释分解。实验为英语，其英语PPG/原型并非本研究跨语言解决方案。

借鉴：判据应依赖声学实现在语音上下文下的意义。不是整个特征必须与内容零相关，也不能从条件化公式推导出本研究尚未观测到的独立性。

## 4. 更值得细化的单候选：参照加权的局部变化证据

### 4.1 统计量

冻结原始第l层实际注意力头的固定平均为P_l；任务原生第l层表征为H_l，宽度保持1024。定义逐帧、逐通道统计：

D_l(t,c) = sum_s P_l(t,s) [H_l(t,c)−H_l(s,c)]^2。

P非负、行和为1。D不是跨空间向量差，也不是将误差越大判为伪造；它表示在参照关系下的局部变化模式。真假可能表现为变化过大、过小，或不同通道/位置的模式差异，应由源分类监督学习。

它可写为：

D = H^2 − 2H ⊙ (PH) + P(H^2)，其中平方与乘法逐元素。

因此不需要构造T×T×1024的全部帧对张量，只有P与H、H^2的矩阵乘法。所有关系操作来自同一输入，教师无梯度；D对任务H保留梯度。数学上D非负，BF16/FP32计算中的舍入负值须单独处理并记录，不能掩盖数值错误。

### 4.2 相比一阶中心化，多观察到了什么

记μ=PH，R=H−μ，有精确逐元素分解：

D = R^2 + [P(H^2)−μ^2]。

第二项是参照权重下的邻域方差。当前帧h=0、两个关系位置为+a/−a且各权重0.5时，R=0，但D=a^2；一阶残差相互抵消，变化统计仍可见。这是数学例子，不是已观察到的真实伪造现象。

固定P时，所有帧共同平移H→H+1b不改变D。说明补充统计不直接依赖这一共同偏移；不等于真实语言变化就是共同平移，更不等于整个分类器语言不变。

### 4.3 如何补充SLS，而非再次强制删除

任务路采用原生XLS-R内部注意力，完整Transformer适配、原卷积冻结。原始路只决定D的比较权重。

主SLS层门控仍按原生H的时间描述生成，主值/BN/SELU/max pool路径保持不变。暂定用相同层权重聚合D，经过独立归一化及同尺度max pool，作为分类前的补充输入。

分类前表示可写为：

u = SELU(W_H pool(H_SLS) + W_D pool(D_SLS) + b_H)。

后续仍是原SLS单一真假分类头。W_H是现有全宽SLS的分类前映射，W_D首次零初始化、无额外bias；补充支路没有独立分类头、原型、192压缩或重建/正交/蒸馏损失。

初始W_D=0时，完整预测精确回到原生SLS，因此若对应共同源预热文件仍在，后端可以在核对后复用。这不同于中心化改变原输入后盲目拷贝旧头。加载时还须保持主路参数/梯度路径与当前纯SLS一致，不能把旧reference模型的detach门控路径误带进来。

按现有22847→1024映射尺寸，W_D增加约2340万参数，是实质性的后端容量增加，必须披露；不能将后续收益全部归因于参照关系，也不称仅几个参数的适配。微调任务路仍是主体，不以这个新增矩阵替代SSL训练。

以上只是具体候选设计，未实现、自检或测量。独立归一化的方式与有限精度处理须实现前定稿，不据目标结果调整。

## 5. 为什么它仍然可能失败

- P如果主要均匀或自关注，D会接近普通全局二阶统计或零。平均注意力头还可能模糊原始有效关系。不能将高熵本身直接等同于完全均匀，应看实际矩阵。
- 正常语音边界、语速、重音也产生变化，D不是天然的伪造标签。只读D会丢失全局伪造信息，所以保留原SLS主体；但这也意味着绝对内容捷径没有被硬性禁止。
- 任务路与D支路可在英语源数据上共同学到不迁移的变化统计，冻结P不提供迁移保证。
- 零初始化允许保住主体，但补充支路可能在源任务很快饱和时没有学到足够作用。须记录其对分类前表示/分数的贡献，不能只记录参数有梯度。
- 若成功，收益可能来自容量或通用二阶特征，而非原始语音参照。少量必要消融留到候选显示希望之后，不提前多臂训练。

与M2/旧M3不做跨体系错误归因：旧方法是冻结SSL的层间transition及双头残差；本候选是微调SSL的帧间参照条件统计加单头SLS。旧失败不能证明本候选必败，但也不赋予它成功证据。
