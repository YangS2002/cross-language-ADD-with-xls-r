# 从文献到问题假设：零目标语料的 XLS-R 跨语言伪造检测

状态：研究笔记；截至 2026-10-03 未据此启动新训练。本文把本项目既有结果当作观察，不把机制假设写成实验结论。DE/UK/ES/ITW 此前已反复看过，后续测试是探索性而非全新盲测。

## 1. 问题必须拆成两种迁移

本任务是仅用 ASVspoof2019 LA 英文训练，测试 MLAAD-DE、MLAAD-UK（乌克兰语）、MLAAD-ES 与 ITW（英语、跨数据集）。零目标语料包括不用目标音频做归一化、无标签适配或超参选择。ITW 不能被当作另一门目标语言。四域 EER 同时受到语言、生成器、录制条件、语料来源和标签构成影响；仅从四域 EER 无法辨识“语言导致失败”。[XLS-R](https://arxiv.org/abs/2111.09296) 的跨语言语音能力，不蕴含其伪造检测边界跨语言有效。

## 2. 文献证据矩阵

| 工作 | 实际提供的证据 | 对本项目的边界或启示 |
|---|---|---|
| [XLS-R, Interspeech 2022](https://arxiv.org/abs/2111.09296) | 大规模多语言自监督表征能迁移到若干语音任务。 | 不能把“跨语言表征”直接称为“跨语言伪造证据”。 |
| [SLS, ACM MM 2024；官方实现](https://github.com/QiShanZhang/SLSforASVspoof-2021-DF) | 利用 XLS-R 层级特征做伪造检测，官方训练允许任务梯度更新 XLS-R。 | 不可误称 SLS 仅做冻结层权重选择；也不能假定多层融合足以解决语言迁移。 |
| [MLSSL, ACM MM 2025](https://arxiv.org/html/2509.03409v1) | 多层门控、局部/全局后端及特征多样性约束，在包括 MLAAD 的数据集上比较；训练用 19LA，选 19LA dev 权重。 | 多层门控/CKA 已有先例；其 checkpoint 选择与本项目最低源域训练损失规则不同。 |
| [Pascu et al., Interspeech 2024](https://arxiv.org/abs/2309.05384) | 冻结 SSL + 简单分类器在其八个数据集上显示强泛化。 | 冻结不是无效对照，但其数据和指标不能代替本项目四域结果。 |
| [Adapter Learning, Interspeech 2024](https://www.isca-archive.org/interspeech_2024/wu24c_interspeech.html) | 在反伪造中讨论全量微调的过拟合，并用冻结骨干+适配器改进其基准。 | 保持与适配可共存；不支持断言本项目只能冻结。 |
| [Layer-Wise Decision Fusion, Interspeech 2025](https://www.isca-archive.org/interspeech_2025/xiao25d_interspeech.html) | 每层先决策后融合，报告 ITW 等跨数据集表现。 | “晚期决策融合”不是未被研究的创新，也没有解决原始与微调状态如何协作的问题。 |
| [Beyond Attacks, Interspeech 2025](https://www.isca-archive.org/interspeech_2025/chandra25b_interspeech.pdf) | 把源域不同攻击当域，研究攻击共性，并测试未见语言。 | 英文源域的攻击标签可作内部压力测试；攻击不变不自动等于语言不变。 |
| [Controlled Cross-Lingual Bias, SPSC 2025](https://www.isca-archive.org/spsc_2025/moreno25_spsc.html) | 在相对受控的合成设置下仍见语言差异。 | 语言可能是独立因素，但本项目异数据集对比无法单独确认。 |
| [Are Audio Deepfake Detectors Polyglots?, 2025](https://arxiv.org/html/2412.17924v2) | 英文模型跨语效果差异大；目标语少量数据常有效。 | 本项目不能使用目标语样本，因此需要在源域开发能够迁移的决策，而非目标语适配。 |
| [Language Orthogonalization, 2026 预印本](https://arxiv.org/html/2609.16458v1) | 用外部 LID 表征去除冻结 SSL 中语言可预测方向，报告未见语言改善；单源语设置某些近语言组合仍可退化。 | “去语言方向”已有直接先例；其冻结 pooled SSL + LID 回归不同于微调与原始状态共存。不能将正交化重新包装为新方法。 |
| [Fine-Tuning Can Distort..., ICLR 2022](https://arxiv.org/abs/2202.10054) | 在视觉 OOD 任务，随机头同步微调会扭曲预训练特征；LP-FT 可缓解。 | 是训练顺序的强对照和机制启发，不是对 XLS-R 本项目失效原因的证明。 |
| [DELTA, ICLR 2019](https://arxiv.org/abs/1901.09229) | 特征保持比单纯参数保持更接近功能约束。 | 保持什么特征、对什么样本保持，仍需要任务解释。 |
| [DR-Tune, ICCV 2023](https://arxiv.org/abs/2308.12058) | 硬性的逐样本特征贴合可能限制任务适配；提出预训练特征分布对任务头的约束。 | 反对“所有层、所有样本的 Fθ≈F0”；视觉结论不可直接当作语音效果。 |
| [One-Class Knowledge Distillation, 2023](https://arxiv.org/abs/2309.08285) | 仅围绕真实语音的教师-学生约束已用于反伪造。 | “只约束真实语音”本身也不是新意；必须说明相较一类蒸馏，双 XLS-R 状态解决的独特机制。 |
| [Feature Genuinization, Interspeech 2020](https://arxiv.org/abs/2009.09637) | 仅利用真实语音特性建模是已有路线。 | 真实语音参照并不自动给出跨语言泛化，尤其源域真实语音只有英文。 |
| [Generalizable Audio Spoofing Detection using Non-Semantic Representations, Interspeech 2025](https://www.isca-archive.org/interspeech_2025/das25_interspeech.html) | 非语义表征在其 OOD 设置具有竞争力。 | 语言/语义信息未必全应保留；但不能假定非语义特征就是稳定的伪造特征。 |

## 3. 本项目现象与不能得出的结论

E2 冻结 raw-layer 五种子的四域均值为 15.99、12.98、16.34、18.72、14.72%，UK 和 ITW 等仍不稳；相对 transition，五个配对种子中四个均值更好。E3 双状态 frozen-reference 三种子的 UK 分别为 30.30、25.12、23.84%，但其 DE、ES、ITW 呈混合效应。E3 同时修改 SSL 微调、前置投影、交叉注意力和后端，故不能从 E2/E3 的差异推断微调是失败原因，也不能推断原始与微调表征没有互补。两头 A/B 在不同域的优劣会反转；头平均不是互补的证据。

“原始 XLS-R=跨语言能力、微调 XLS-R=伪造能力”是研究叙事，尚不是机制结论。即使原始特征更跨语，其冻结检测器也可能缺乏新生成器敏感度。仅用英文源域约束真实语音也未必对乌克兰语或西班牙语真实语音有效。

## 4. 化简竞争解释

* H1：**任务适配造成可用表征或判别边界漂移**。预测：相同检测头与训练流程下，微调比冻结改善源域/部分攻击，却恶化某些未见攻击；漂移与错误有关。若最简单 LP-FT 就稳定改善，复杂双路法的必要性降低。
* H2：**冻结表示已有足够伪造信息，但后端融合丢失或误用**。预测：同一冻结特征下，简洁单头/逐层决策优于现有双头复杂融合；改变骨干并非必要。
* H3：**源域攻击特有线索主导**。预测：留一攻击类型的源域验证会在个别攻击明显恶化；原始/微调差值主要编码攻击身份而非真假共性。即使保护原始表征也未必解决。
* H4：**语言本身造成决策偏移**。现有四域异语料 EER 不足以检验；需要受控同生成器多语言数据或更谨慎的成对设计。2026 正交化论文已经直接研究这一方向。

优先级：先区别 H1/H2/H3；不要把 H4 当成已被本项目证实。采样率及输入协议已知值得专项研究，但按当前要求保持不变，不作为本轮主要归因。

## 5. 实验前可成立的研究出发点

**跨语言伪造检测不是简单“保留语言信息”或“删除语言信息”，而是源域监督下的伪造判别如何在预训练语音参照中更新，同时避免把训练攻击和语言/语料特征当作可迁移证据。** 研究对象是*更新的功能*，不是再堆一层融合模块。原始 XLS-R 应被视为参照，不能先验宣称其每个维度都应保持，也不能先验宣称微调差值必然是伪造残差。

有价值的候选命题是 **“参照约束的选择性任务适配”**：保留冻结的 F0 与可微调 Fθ，但约束应作用于可说明的功能/决策，而非无差别逐层 L2；需要允许伪造证据出现变化，同时保护真实语音的参照决策。与冻结适配器、SLS 层选择、语言正交化、单纯拼接/平均的研究问题不同，但与真实语音一类学习/蒸馏存在近邻，**不能凭名称保证创新性**。具体函数形式不能仅凭文献决定，应由下述源域诊断筛选后在训练前锁定。

## 6. 在新模型训练前必须完成的判别性诊断

1. 核查现有 E2/E3 权重、评估日志与源域训练损失，固定相同输入与标签方向；不得用目标域挑头或权重。
2. 在**仅英文源域**的保留集上，比较冻结/微调各层表征及同一读出头的分数；分别统计真实语音与各攻击类型，不能只报全样本平均 cosine 或 CKA。
3. 现有 E3 已在所有源域训练攻击上训练，**不能**把它按攻击分组的读数称作“留一攻击验证”。留一攻击类型需要另起配对训练，属于后续实验；不能拿现有权重回顾性冒充未见攻击测试。
4. 对已有双状态模型做原始路/任务路遮蔽、固定头的预测差值诊断，确认“两个状态均被用到”而非只是容量增加。
5. 若 H1 无迹象、H2 或 H3 更强，放弃真实语音锚定主线；不能继续用它作为论文结论。

诊断后先写预注册方案：单一主因素、同构容量匹配对照、一个预定种子工程筛查；有希望才扩展至预定的另外两个种子。目标数据只用于锁定模型后的报告，列全部 DE/UK/ES/ITW、每种子均值和最差域；ITW 单列为跨数据集英语压力测试。只按源域最低训练损失保留神经网络权重。不改 data.pad、不重采样、不用 RawBoost/加噪、不研究样本顺序，不把多次目标域探索称为独立盲测。

## 7. E3 既有权重的源域诊断预注册（待 SSH 恢复）

SSH 最近已知端口 30351、上一端口 30521 在本次尝试均返回连接拒绝；因此以下是执行前规则，**不是已得到的结果**。

固定使用 E3 `frozen_reference_seed20/best_train_loss.pth`，不因此前目标域结果选择另一权重。原始 XLS-R 为其官方初始化 `F0`，任务 XLS-R 为该 checkpoint 的 `Fθ`。仅访问 ASVspoof2019 LA 英文源域训练标签和音频；固定排序后，从全部真实音频与每个源域攻击类别各取相同预定数量（每组不超过 64），不依据预测或目标域信息抽样。保持原 `torchaudio.load` + `data.pad`；双 SSL 关闭 dropout/masking；诊断不更新参数。

逐层记录：（a）同音频的 `F0` 与 `Fθ` 余弦距离，（b）相对范数变化，（c）按真实/各攻击分组的均值与分位数。再保持 E3 整个 checkpoint 不变，只将参考输入在前向时从 `F0` 替换为当前 `Fθ.detach()`，比较 bona fide logit、按组错误率和分数变化比例。这是单 checkpoint 的**参考路遮蔽**，不等于训练一个容量匹配对照；差异只能表明 E3 是否依赖该路。

判别规则：若变化几乎全部近零且遮蔽不改变分数，E3 并未实际利用原始/微调状态差，参照约束主线缺少必要条件；若变化可观但同样出现在真实和所有伪造组，不能称之为伪造创新；若真实/伪造及攻击间有结构化差异，仅能支持进一步做严格配对实验，不能从源域诊断推出跨语收益。任何一种结果都不准改写成“语言信息已被保留/破坏”。
